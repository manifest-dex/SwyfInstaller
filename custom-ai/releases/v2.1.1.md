FlagshipRouter is now the default, auto-enabled provider for the **Scam With Your Friends full release**, Steam app **4954910**, build **25965579**.

## What's changed

- Default settings are `enabled: true`, `baseUrl: http://127.0.0.1:20128/v1`, `model: gpt-6-astra`, JSON Schema mode. Fresh installs work once FlagshipRouter is running; never-configured files migrate automatically.
- Missing `settings.json` is treated as enabled (game bridge + panel store).
- F8 panel gains a FlagshipRouter card with a one-click defaults button.
- Installer writes the FlagshipRouter defaults on fresh install and preserves existing keys.

## How to update

1. Close the game and the AI Settings panel.
2. Update **SwyfInstaller to v2.1.1** and press **Setup FlagshipRouter** (or start FlagshipRouter manually with `npm run launch -- --host 127.0.0.1`).
3. In the router dashboard create an API key under **Endpoint & Key** if required and pick a **Ready** model under **Models**.
4. Press **Install**, then launch the game and open **F8** to check your settings.

**Manual installation:** Extract the complete ZIP into the full release's game folder and run **Install Custom AI.cmd**.

Settings, sign-in and backups already in that folder are preserved.

Major game API changes may still require another mod update.
