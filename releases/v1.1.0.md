## Added

- Sign in with ManifestDeX to use the community AI service when it is available.
- View your membership, rank, remaining personal allowance and reset times in AI Settings.
- Choose whether to disable the original Kolkata backend during installation.

## Improved

- AI Settings shows the provider currently saved for the game and clearly marks unsaved changes.
- Connection tests explain when tested settings still need to be saved.
- Membership and quota information refresh while the settings panel is open.
- Updating the mod preserves private provider settings and verified game backups.

## Fixed

- Sign-in failures display an explanation instead of immediately closing the browser tab.
- Repeated sign-in attempts respect the server's retry delay.
- A canceled or disconnected sign-in cannot overwrite a newer account connection.
- Account and connection status endpoints return their expected data reliably.
- Earlier installations migrate to the current hooks without retaining obsolete authentication overrides.

## Installation and upgrade

1. Close the game and its AI Settings panel. Wait for Steam downloads to finish.
2. Extract the complete ZIP into the game directory, then run **Install Custom AI.cmd**.
3. Start the game and press **F8**. Select **Use ManifestDeX AI**, sign in and approve access, then click **Save Settings**.

ManifestDeX AI must be enabled and configured by the service administrator. Your own OpenAI-compatible provider remains available. Only the lobby host's settings control game AI. Speech recognition and voice synthesis remain handled by the game.

Temporary localhost test sessions are separate from production. Install this production build and sign in again; your private provider settings are retained. The release uses `https://swyf-ai.manifestdex.com`.

Requires Windows x64, a compatible Mono Playtest build, and ASP.NET Core Runtime 10 x64. No game binaries, local credentials or conversation logs are included. Responses depend on the selected provider/model; no universal response-quality guarantee is made.
