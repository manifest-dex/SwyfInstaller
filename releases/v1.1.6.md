Adds **FlagshipRouter** as the default, auto-enabled provider, plus one-click setup.

## What's changed

- Fresh installs auto-enable the mod with `http://127.0.0.1:20128/v1` / `oc/union-alpha` (existing settings and API keys preserved).
- New **Setup FlagshipRouter** button: clones/updates `%LOCALAPPDATA%\FlagshipRouter`, runs `npm install` (via `cmd.exe`, output streamed to Details), starts it on `127.0.0.1:20128`, and points the mod at it.
- New **Test router** button (POSTs a tiny chat completion with the saved mod key) and **Open dashboard** button.
- Fixed `npm install failed (exit 1)`: `.cmd` files now run through `cmd.exe /c` with captured logs.
- F8 panel: FlagshipRouter preset card + **Use FlagshipRouter defaults** button.
- Console installer: new menu option `6) Setup FlagshipRouter`.
- Version bump to **1.1.6** (installer + mod).

## How to update

1. Close the game and the AI Settings panel.
2. Run **SwyfInstaller-Setup-v1.1.6-win-x64.exe**, or let the existing app update itself.
3. Press **Setup FlagshipRouter**, then open `http://localhost:20128/dashboard` (default password `123456`): **Endpoint & Key** → create a key if required, **Models** → pick a **Ready** model.
4. Press **Test router**, then in-game press **F8** to verify and **Save Settings**.

Existing settings and backups are preserved. The setup includes the installer app; it downloads and verifies the mod separately.
